# AnimePlay — Android-проект (0.1.6-dev)

AnimePlay — приложение-каталог аниме на Kotlin и Jetpack Compose с тёмной фиолетово-розовой темой.

## Настройки оформления и каталог

- 4 палитры оформления: «Орхидея», «Сакура», «Неоновая фуксия», «Лавандовый вечер»;
- 3 набора значков нижней навигации: контурные, неоновые и пастельные;
- 3 варианта иконки приложения на рабочем столе, переключаемых в профиле;
- 3 плотности каталога: компактная сетка из 3 колонок, стандартная из 2 колонок и крупные карточки в 1 колонку;
- выбранные настройки внешнего вида сохраняются на устройстве;
- общий каталог аниме с поиском, жанрами, карточками и подборкой Yuri / Girls' Love (GL), также известной как сёдзё-ай.

## Каталог

Метаданные, жанры, постеры, описания и рейтинги загружаются из AniList. AniList не предоставляет сами видеофайлы. Каталог не ограничен только юри: доступны распространённые жанры аниме из общего каталога.

## Русская озвучка и видеоисточники

### AniLibria / AniLiberty

На странице аниме есть поиск релизов через публично документированные методы API V1, выбор серии, HLS-качества и воспроизведение в Android Media3. Приложение уважает признаки региональной и правообладательской блокировки и не пытается их обходить. Офлайн-загрузка HLS в этой версии не реализована.

### Студийная Банда / Studio Band

Добавлен переход на официальный сайт: https://www.studiobandme.ru/ . Публично документированный API/SDK для встроенного плеера при подготовке проекта не найден, поэтому AnimePlay не извлекает и не копирует видео с сайта. Для встроенного просмотра требуется документация/API от студии и разрешение на интеграцию.

### Собственные источники

Можно сохранить HTTPS-ссылку и субтитры при наличии права на использование материала. Встроенная загрузка поддерживает прямые MP4/M4V/WebM-ссылки. Потоки HLS воспроизводятся, но не загружаются в офлайн в этой версии.

## Сборка APK на Windows

1. Установи Android Studio и JDK 17.
2. Распакуй архив и открой в Android Studio корневую папку `AnimePlay`, где находятся `settings.gradle.kts` и `build.gradle.kts`.
3. Дождись синхронизации Gradle и установки требуемой версии Android SDK.
4. Нажми **Build → Build Bundle(s) / APK(s) → Build APK(s)** либо запусти `СОБРАТЬ_APK.bat`.
5. При успешной сборке файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

Проверка проекта скриптом `python scripts/verify_project.py` проверяет структуру и важные элементы, но не заменяет компиляцию Kotlin/Gradle. APK в этой рабочей среде не собран.

## Перед публикацией в Google Play / RuStore

Необходимо отдельно проверить условия API и брендинга AniList/AniLiberty/Studio Band, наличие прав на постеры, видео и озвучки, возрастную маркировку, политику конфиденциальности и актуальные требования магазинов. AnimePlay не является официальным приложением перечисленных студий или площадок.


## Новое в версии 0.1.4-dev

- Вкладка «Календарь» показывает будущие серии, известные AniList на ближайшие 21 день, с датой и местным временем.
- В 0.1.4 профиль ещё содержал 12 оригинальных портретов-заглушек; в 0.1.6 они заменены выбором персонажа из любимого аниме. Пять рамок сохранены.
- В карточке каждого аниме можно поставить оценку от 1 до 5 и сохранить текстовый отзыв. Отзыв можно позже изменить.
- Важно: отзывы пока локальные и не видны другим пользователям. Общая лента потребует отдельного сервера и модерации.
- Расписание AniList может обновляться или меняться; кнопка обновления загружает последние опубликованные данные.


## Новое в версии 0.1.5-dev

- Выбор аватара по любимому аниме: поиск тайтла через публичный Kitsu JSON:API, затем выбор персонажа из списка персонажей этого тайтла.
- Сохраняются имя персонажа, название аниме и HTTPS-ссылка на портрет; само изображение не копируется в APK.
- Добавлены личные списки: «Смотрю», «Просмотрено», «В планах», «Отложено» и «Брошено». Статус меняется на странице аниме и отображается в профиле.
- Списки и выбранный персонаж сохраняются локально на устройстве; аккаунт и синхронизация между устройствами пока не подключены.
- Kitsu описывает публичные GET-endpoints и связь anime → characters в официальной API-документации. Права на сами изображения и условия использования API/материалов необходимо отдельно подтвердить до публикации в магазинах.
- Прежний AniList-каталог/календарь требует отдельной юридической проверки или замены до публичного релиза: действующие условия AniList ограничивают использование API в конкурирующих anime/manga tracker сервисах.



## Важное до публикации

Текущая интеграция каталога и календаря использует AniList. Его действующие API Terms запрещают использование API в конкурирующих anime/manga tracker/list services. Для публичного выпуска необходимо получить письменное разрешение AniList либо заменить каталог и расписание на поставщика с подходящими условиями. Кроме того, использование изображений персонажей Kitsu требует отдельной проверки прав и условий источника. Текущий ZIP — dev-проект, не готовая публикационная сборка.


## Новое в версии 0.1.6-dev

- В профиле можно найти аниме по названию, затем выбрать персонажа этого тайтла из каталога Kitsu; список подгружается до 60 записей страницами, а персонажа можно найти по имени. Выбранный портрет показывается с рамкой.
- Убраны универсальные сгенерированные аватары-заглушки: до выбора персонажа профиль показывает нейтральный знак, а не выдаёт вымышленную картинку за героя конкретного аниме.
- Карточки пяти списков просмотра кликабельны: открывается список с постерами и названиями тайтлов, запись можно убрать из списка.
- Уточнена локальная модель: аватар и списки просмотра сохраняются только на этом устройстве, облачных аккаунтов и общей социальной ленты пока нет.
- Для изображений персонажей используется внешний Kitsu URL; само изображение не копируется в APK. Права на персонажные изображения и коммерческое использование API необходимо проверить до публикации.

## Важное ограничение данных

Каталог и календарь прототипа всё ещё используют AniList. Действующие условия AniList API запрещают использование API в конкурирующих, некомплементарных приложениях той же природы, включая аниме/манга-трекеры и списки просмотра. Для публичного AnimePlay необходимо письменное разрешение AniList или замена этого источника на поставщика с подходящими условиями. См. действующие условия: https://docs.anilist.co/guide/terms-of-use .

Эта версия — рабочий Android Studio-проект. APK в текущей среде не собран и не прошёл тест на устройстве. Статические проверки не заменяют Android/Gradle-сборку.
