# AnimePlay 0.1.6-dev — статус проекта

## Реально добавлено в эту версию

- Отдельная вкладка «Календарь серий» в нижней навигации.
- Календарь получает расписание будущих эпизодов из AniList на ближайшие 21 день (до пяти страниц по 50 записей (до 250 за загрузку)), группирует их по дате и показывает номер серии и время в часовом поясе телефона.
- Кнопка ручного обновления расписания и понятные состояния загрузки/ошибки/пустого календаря.
- 5 вариантов рамки аватара: без рамки, сакура, лаванда, неон, сердечки.
- Выбор персонажа для аватара и рамки сохраняется в SharedPreferences и восстанавливается после перезапуска.
- Отзывы и оценки 1–5 звёзд на странице каждого аниме.
- Пользователь может создать отзыв и изменить свой отзыв для конкретного аниме; текст ограничен 1200 символами.
- Отзывы и оценки сохраняются локально на этом устройстве; публичная межпользовательская лента/аккаунты пока не реализованы.
- Предыдущие функции проекта 0.1.3 сохранены: каталог, жанры, Yuri/GL, поиск AniLiberty, Studio Band link, плеер, избранное, загрузки и кастомизация оформления.

## Источники и ограничения

- Расписание серий: AniList GraphQL `Page.airingSchedules` с фильтрами `notYetAired`, `airingAt_greater`, `airingAt_lesser` и сортировкой по времени. Расписание может изменяться студиями; даты в приложении являются данными каталога, а не гарантированным временем публикации на видеоплощадке.
- AniList предоставляет метаданные и расписание, но не видеофайлы.
- Отзывы пока видны только локально на конкретном телефоне. Для общей публикации между пользователями потребуется сервер, регистрация/защита от спама, правила сообщества и модерация.
- Портрет персонажа загружается удалённо из Kitsu; права на изображения не подтверждены и требуют отдельной проверки перед публикацией.
- Правила прав на видео, постеры и озвучки из предыдущей версии остаются в силе.

## Проверки

- Статический скрипт проверяет состав проекта, XML-манифест, зависимости, расписание, модель/хранилище отзывов, выбор персонажа Kitsu, статусы списков и наборы рамок.
- APK не собран; Android SDK и Gradle не установлены в рабочей среде. Статические проверки не заменяют Kotlin/Android-компиляцию и запуск на телефоне.


## 0.1.5-dev — изменения предыдущей рабочей копии

- Добавлен поиск аниме и выбор персонажа из его character relationship через Kitsu API.
- Выбранный персонаж хранится на устройстве по HTTPS URL и показывается в шапке профиля с выбранной рамкой.
- Добавлены пять локальных статусов списка просмотра и быстрый выбор статуса в карточке аниме.
- Профиль показывает количества по статусам и пять последних изменений.
- Статус: исходники обновлены. Статическая проверка возможна; Gradle/Android SDK отсутствуют, поэтому APK и компиляция пока не подтверждены.


## 0.1.6-dev — изменения этой рабочей копии

- Убран универсальный аватар-заполнитель. В профиле можно искать аниме через Kitsu, загрузить до 60 связанных персонажей постранично и отфильтровать их по имени; портрет сохраняется по проверенному HTTPS URL.
- Пять карточек списков просмотра открывают отдельный список тайтлов с постерами/названиями; пользователь может удалить запись.
- Статические проверки проекта: 50 проверок пройдены. Kotlin-файлы были переданы компилятору для проверки синтаксического разбора, но полная компиляция не выполнена: отдельно запущенный kotlinc не имеет Android/Compose и других зависимостей проекта.
- APK не собран и на устройстве не запускался.

## Блокеры публичного релиза

- В текущем прототипе основной каталог и календарь всё ещё обращаются к AniList. Действующие условия AniList прямо запрещают использование их API в конкурирующих, некомплементарных сервисах каталогов/трекеров. До публикации AnimePlay требуется письменное разрешение AniList либо полный переход на источник с подходящими условиями.
- Для динамических изображений персонажей используется Kitsu API; официальная документация описывает публичные GET-запросы и связи anime → characters, но права на изображения и конкретные условия коммерческого использования необходимо отдельно согласовать/подтвердить.
- Также остаются обязательными права на видео и озвучки, сервер для общих отзывов/учётных записей и модерация пользовательского контента.
