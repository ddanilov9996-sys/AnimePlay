# Как получить APK AnimePlay без установки Android Studio на своём компьютере

В проект добавлен GitHub Actions workflow `.github/workflows/android-apk.yml`. Он собирает **debug APK** на сервере GitHub с JDK 17, Android SDK API 37 и Gradle 9.6.0.

## Шаги
1. Создайте репозиторий на GitHub и загрузите в него содержимое папки `AnimePlayApp`.
2. Откройте вкладку **Actions** репозитория.
3. Выберите workflow **Build AnimePlay APK**.
4. Нажмите **Run workflow** и дождитесь зелёной галочки.
5. Откройте завершённый запуск и скачайте artifact **AnimePlay-debug-apk**.
6. Распакуйте скачанный artifact — внутри будет `app-debug.apk`.
7. Перенесите APK на Android и установите. Для установки может потребоваться разрешить установку приложений из выбранного источника.

## Важно
- Это debug APK для проверки, не подписанный релизный APK для публикации в магазинах.
- Для Google Play нужен подписанный release bundle (AAB), ключ подписи и проверка политик/прав на каталог, постеры, озвучки и видео.
- Workflow не доказывает, что приложение прошло runtime-тесты на реальном устройстве; после сборки нужно проверить запуск, поиск, расписание, профиль, отзывы, плеер и загрузки.
- Перед публичным выпуском требуется решить ограничения источников данных, описанные в `BUILD_STATUS.md` и `DATA_SOURCES.md`.
